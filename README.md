## What is Baseball Game Creator?
Baseball Game Creator (BGC) is a Windows application I designed in 2020 for baseball fans to simulate their own baseball games using custom teams and pitch input. My application processes baseball pitch input to simulate a real-life baseball game for users to be creative and bring their fantasy leagues to life. The product is specifically designed to work hand-in-hand with [pitchback nets](https://www.bing.com/search?q=what+is+a+baseball+pitchback+net&cvid=1514de3b522d4af9bed4f5234e765152&gs_lcrp=EgRlZGdlKgYIABBFGDkyBggAEEUYOTIGCAEQABhAMgYIAhAAGEAyBggDEAAYQDIGCAQQABhAMgYIBRAAGEAyBggGEAAYQDIGCAcQABhAMgcICBDrBxhA0gEINDkzNWowajmoAgiwAgE&FORM=ANAB01&adppc=EDGEESS&PC=HCTS), a tool that baseball players use to practice pitching and ground balls. Users can use BGC to enter their pitch data and pretend like they are playing a real baseball game!

## App Features
- Set Rosters: Users can set custom rosters for their team names, starting lineup, starting pitchers, bench players, and bullpen. If a user does not fill out all boxes on the screen, the app will automatically fill the empty positions with a placeholder player. BGC simulates one game at a time!
- Baseball Game Screen: The heart of BGC, the game screen is where a user will click the strike or ball buttons to enter their pitch data. After each pitch, the game will update with an action. This could be a hit, a home run, a strikeout, a walk, and more! Version 1.0.1.3 revises the BGC algorithm completely to make games seem more realistic!
- Game Log Screen: A secret feature not put on the BGC home page is that the app tracks everything that happens in your game! On the Game Log Screen, users have the option to save their game's game log to their local machine. This means users can save their awesome game logs to keep forever!
